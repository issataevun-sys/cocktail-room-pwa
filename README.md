# COCKTAIL ROOM — PWA (тестовая версия)

Отдельный **публичный** репозиторий только с безопасными статическими файлами офлайн-прототипа.

## Статус
- Можно установить на Windows, MacBook, iPhone и iPad (при поддержке браузера).
- Локальные тестовые смены, кальяны и гости записываются в IndexedDB.
- Service Worker сохраняет интерфейс для повторного открытия без интернета.
- Страница «Установка и офлайн» позволяет проверить техническую готовность устройства.
- **Нет подключения к рабочей Google Таблице или Apps Script.**
- **Нет авторизации и защищённой синхронизации.**
- **Не вводите реальные имена, номера телефонов и финансовые данные.** Очередь outbox пока локальная и никуда не отправляется.

## Опубликовать сайт
1. Откройте **Settings → Pages** в этом репозитории.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Перейдите в **Actions → Publish Cocktail Room PWA test shell** и запустите **Run workflow**, если автоматический запуск не произошёл.
4. Дождитесь результата Deploy — в нём появится действующий адрес HTTPS.

Workflow публикует только `index.html`, `app.js`, `db.js`, `shifts-ui.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и `icon.svg`. Серверный код из приватного проекта здесь отсутствует.

## Проверка
После первого открытия зайдите в «Установка и офлайн», дождитесь готовности кэша, установите приложение и повторно откройте его без интернета. Проверяйте только на вымышленных тестовых данных.

## Что дальше
Защищённый серверный API, роли сотрудников, учёт устройств и синхронизация реальных смен. Пока не разработаны и не подключены.

## v0.7 — безопасный переход в рабочую версию и проверка Google-сессии

- «Рабочее приложение» предлагает сохранить адрес Google Apps Script `/dev` или `/exec` **только на текущем устройстве**.
- Кнопка «Открыть рабочую смену» запускает существующую Google Apps Script версию в новом окне — авторизация и права по-прежнему проверяются там.
- Кнопка «Проверить доступ» использует диагностический iframe-посредник `?view=bridge`; **он не передаёт реальные данные и не выполняет запись**. Требуется обновить `backend/Code.gs` и создать `backend/PwaBridge.html` в приватном Apps Script проекте.
- Проверка может не пройти, если браузер запрещает сторонние cookies Google во встроенном окне. Это не означает, что вход в Google Apps Script отдельной вкладкой перестал работать.
- Добавлено восстановление **только тестовой** JSON-копии в пустую IndexedDB. Данные уже существующей локальной базы не перезаписываются.
- Кэш обновлён до `cocktail-room-shell-v4`; для обновления установленной PWA следует перезапустить её (при необходимости дважды).
- Архив 329 смен, гостевая база и рабочая смена не переносятся в общедоступный репозиторий.

### Оставшиеся ограничения
Эта версия НЕ реализует общую рабочую смену офлайн, не переносит в PWA персональные данные и не позволяет работать с реальным Google Sheets при отсутствии интернета. Для этого требуется полноценная серверная авторизация, проверка Google-аккаунта, управление ролями и устройствами, защищённое локальное хранение, отправка очереди и проверка конфликтов при реальном восстановлении сети. Нельзя безопасно включить эти функции простой публикацией статики или сохранением владельческого Google-токена.
