COCKTAIL ROOM · защищённый обмен

Тест новой связи без Google Cloud: сообщение шифруется на iPhone, отправляется в отдельный Apps Script и возвращается зашифрованным. Apps Script проверяет подпись запроса, а iPhone расшифровывает ответ.

Только тест. Используй отдельный Apps Script SecureStagingSync.gs, не рабочую базу. Не вводи здесь реальные имена гостей, PIN, телефоны или данные смены. Ключ сопряжения нигде не публикуй.

Ожидаем запуска. Для этого теста секрет не сохраняется в браузере.
Google Sheets не затрагивается. Зашифрованные тестовые данные сохраняются в Script Properties и остаются после перезапуска браузера. Это тестовое, ограниченное по размеру хранилище — не база реальных смен. Секрет потребуется ввести заново. POST подтверждается отдельным серверным чтением.
